# جسر التحول — صوت الموظف

منصة ويب للجوال يشغّلها **سفير التغيير** في منشأة صحية أثناء الانتقال إلى شركة الصحة القابضة.
يفتحها الموظف من جواله بلا حساب فيسأل أو يشارك مخاوفه أو تحديًا أو اقتراحًا أو شائعة سمعها،
وتصل المشاركة **مجهولة المصدر** إلى لوحة سفير التغيير، ثم تُنشر الإجابة الرسمية ويتابعها برمز.

> **الحالة:** المرحلة صفر — التهيئة ونظام التصميم. لم تُبنَ أي ميزة بعد.
> المراحل ومعايير القبول في [`PLAN.md`](./PLAN.md)، وقواعد العمل في [`CLAUDE.md`](./CLAUDE.md).

## البدء

```bash
pnpm install
cp .env.example .env.local   # املأ القيم — ولا ترفع هذا الملف
pnpm dev                     # http://localhost:3000
```

معرض نظام التصميم: [`/kitchen-sink`](http://localhost:3000/kitchen-sink)

## الفحوصات

```bash
pnpm verify   # lint + typecheck + test
pnpm e2e      # مسارات Playwright
pnpm budget   # ميزانية الحزمة الأولى (بعد pnpm build)
```

## الخصوصية أولًا

- لا حقل اسم ولا رقم وظيفي ولا بريد ولا جوال — **ولا أعمدة لها في قاعدة البيانات**،
  يمنع ذلك اختبار في CI.
- لا تسجيل لعناوين IP، ولا تحليلات طرف ثالث في واجهة الموظف.
- كل لون في الواجهة من دليل الهوية الرسمي — يمنع الخروج عنه اختبار في CI.

## أصول ناقصة قبل التسليم

(`public/brand/README.md`).
